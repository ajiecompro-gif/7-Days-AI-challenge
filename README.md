# Creators Acane: 7 Days AI Challenge

Complete static website with two WhatsApp packages, seven proof screenshots and two videos.

## Deploy to Vercel

Import this repository in Vercel. Select framework Other, leave the build command empty and use the repository root as the output directory. No environment variables are required.

Edit index.html for page content, style.css for styling, and app.js for WhatsApp messages and gallery items.
